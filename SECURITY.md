# Política de Segurança

Este projeto é desenvolvido para a disciplina de Engenharia de Software da Universidade Federal de São Paulo (UNIFESP).

## Dados Fictícios e Ambiente Acadêmico

O sistema utiliza **exclusivamente dados fictícios e simulados** para fins educacionais e de demonstração acadêmica. Nenhuma informação pessoal ou institucional real de alunos, docentes ou gestores é armazenada ou processada.

## Relato de Vulnerabilidades

Caso você identifique qualquer vulnerabilidade de segurança neste repositório:

1. Utilize o recurso oficial de **Private Vulnerability Reporting** do GitHub (disponível na aba **Security** > **Report a vulnerability** do repositório).
2. Por favor, **não crie issues públicas** ou comentários abertos para relatar vulnerabilidades de segurança.
3. Ao enviar o relatório confidencial, descreva o problema identificado, o impacto potencial e, sempre que possível, passos para reproduzi-lo.

A equipe responsável pelo projeto analisará o relatório e tomará as devidas providências.
